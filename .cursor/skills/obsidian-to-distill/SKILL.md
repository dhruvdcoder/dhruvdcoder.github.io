# Obsidian → TMA post

Turn an Obsidian `.md` note into (or into a section of) a blog post in this repo.

## Inputs

- **Source**: absolute path to an Obsidian note (often outside the repo, e.g. OneDrive vault).
- **Target**: existing post/draft, or a new file under `_posts/` or `_drafts/`.

If the target is unclear, ask: merge into an existing post, or create a new one?
New essays stay in `_drafts/` unless the user asks to publish (`_posts/`).

## Workflow

1. **Read both files** — source note + target post (or an existing example: `_drafts/2026-05-10-continuous-time-markov-chains.md`, `_drafts/2026-08-21-discrete-diffusion-language-models-explained.md`, `_drafts/2023-06-21-transformers.md`).
2. **Extract content** — keep substantive prose, definitions, proofs, and equations. Drop Obsidian-only scaffolding (see conversions below).
3. **Adapt to the post** — rewrite into the post’s voice and structure; do not dump the note verbatim.
4. **Update bibliography** — add cited works to `_bibliography/references.bib`; cite with `{% cite bibKey %}`.
5. **Polish** — fix clear typos; skip incomplete stubs (empty Anki cards, “TODO”, unfinished proofs unless the user wants them kept).

## Post shape

Posts use the default `post` layout (no `layout:` key). Prefer this front-matter pattern:

```yaml
---
title: "..."
subtitle: "..."
kicker: "LLMs"          # display eyebrow: Math / Machine Learning / LLMs / ...
role: "PhD Researcher, UMass Amherst"
date: YYYY-MM-DD       # created / first published
updated: YYYY-MM-DD    # last substantial revision; omit until the first one
tags: [language-models]
excerpt: "..."
tikzjax: true            # only if the post has TikZ figures
bibtex: |
  @article{patelYYYYslug,
    title   = {...},
    author  = {Patel, Dhruvesh},
    journal = {The Middle Author},
    year    = {YYYY},
    month   = mon,
    url     = {https://dhruveshp.com/YYYY/MM/DD/slug/}
  }
---
```

- **date** is created / first published (filename date and URL). **updated** is the last substantial revision. Omit `updated` until there is one; the byline then shows only Created.
- **Kicker** is the article eyebrow (human-readable, may have spaces). **Tags** are kebab-case archive slugs and need a `tags/<tag>.md` page if new (`layout: tag-archive`).
- Front-matter `bibtex:` is “cite this article” (not the works the post cites). Use `@article` with `journal = {The Middle Author}`, `year` / `month` from `date`, and the permalink as `url`. The prose cite line is generated from those fields.
- Body headings: `##` / `###`. TOC is generated by JS from those headings — do not add a `toc:` list.
- Optional callouts: `<details class="callout callout--note" markdown="1">` or `<div class="callout" markdown="1">`.
- Prose line breaks: break only at punctuation (sentence/clause boundaries). Prefer one sentence per line.

## Obsidian → post conversions

| Obsidian | TMA post |
|----------|----------|
| YAML frontmatter (`tags`, `aliases`, `anki_*`, `publish`, …) | Drop; use the front matter above |
| `# Title` matching the note title | Omit if `title:` already covers it; otherwise demote to `##` |
| `>[!anki]` / `>[!note]` / callouts | Unfold into prose or `<div class="callout">` / `<details class="callout">`; do not keep Obsidian callout syntax |
| `[^ref]` bibliographic footnotes | `{% cite bibKey %}` + entry in `_bibliography/references.bib` |
| `[^n]` asides (docs, remarks) | Keep as Kramdown `[^n]` |
| `[[Wiki Links]]` to papers | `{% cite bibKey %}` |
| `[[Wiki Links]]` to concepts | Plain text or a markdown URL |
| `#tag` / block ids (`^feff9e`) | Drop |
| ` ```tikz ` fences | TikZJax `<figure class="tikz-figure">` — see **TikZ** below |
| `![[Pasted image …]]` | Copy to `assets/img/posts/` and embed with `<img>` |
| `t'`, `\Lambda'(t)` in math | `t^{\prime}`, `\Lambda^{\prime}(t)` — see **Kramdown smart quotes** |
| `\{...\}` literal braces in math | `\\{...\\}` or `\lbrace...\rbrace` — see **Kramdown escaped braces** |
| Incomplete Anki / empty sections | Skip unless the user asks to keep drafts |

### Citations (jekyll-scholar)

Shared library: `_bibliography/references.bib`.
Reuse keys across posts.

```liquid
... as shown by Schlag et al. {% cite schlagLinearTransformersSecretly2021 %}.
```

At the end of the post:

```markdown
## References

{% bibliography --cited_in_order %}
```

Prefer real BibTeX (Zotero MCP, arXiv) over placeholders.
Do not hand-write a numbered `### References` list on new posts.
Existing drafts (CTMC, diffusion) may still use `[[n]](#references)` — leave them unless asked to migrate.

External non-paper links stay as markdown URLs.

### Math (MathJax)

Site loads MathJax with AMS tags (`_includes/mathjax.html`).
Inline: `$...$` · Display: `$$...$$`.

- Prefer `$$` for single-line display equations.
- Multi-line: wrap in `$$...$$` and use `aligned` (not `align`) so Kramdown preserves `\\`.
- `\color{gray}` is fine.
- Avoid `align*` in Markdown — the trailing `*` is parsed as emphasis.

```markdown
$$
\begin{aligned}
a &= b \\
c &= d
\end{aligned}
$$
```

#### Kramdown smart quotes (primes in math)

Kramdown converts ASCII `'` inside math to `&#8217;`, which breaks MathJax.

**Rule**: inside any math, replace every `'` used as a prime with `^{\prime}` (`t'` → `t^{\prime}`, `\Lambda'(t)` → `\Lambda^{\prime}(t)`).

#### Kramdown escaped braces

Kramdown strips the backslash from `\{` / `\}`.
Use `\\{...\\}` or `\lbrace...\rbrace` for *visible* set braces.
Do **not** double-escape TeX grouping (`\mathbb{R}`, `e^{-\lambda t}`).

### TikZ figures

Use the **distill-tikz** skill.
Convert each Obsidian ` ```tikz ` fence to:

```html
<figure class="tikz-figure">
<div class="tikz-panel">
  <script type="text/tikz">
\begin{document}
...existing tikzpicture...
\end{document}
  </script>
</div>
<figcaption><b>Figure N.</b> Caption.</figcaption>
</figure>
```

Set `tikzjax: true` on the post.
TikZJax constraints (no `pgfplots`, `\begin{document}` wrapper, punctuation/decimals outside `$...$` in node text) are in that skill.

### Content judgment

- **Correct obvious note errors** when adapting.
- **Preserve technical meaning**; tighten wording for a public post.
- **Keep citations.** Omit `# Hypotheses`, `# Ideas`, and other open/research-question blocks unless the user asks to keep them.
- **Skip incomplete stubs** (empty subsections, trailing “read X for a description”).
- **Merge mode**: extend an existing section rather than duplicating it. Bump `updated` to today; do not change `date` or the filename.
- **Do not commit** unless the user asks.

## Checklist

```
- [ ] Source read; target file chosen/created
- [ ] New post: `date` only. Revising an existing post: bump `updated`, leave `date` / filename alone
- [ ] `bibtex:` is `@article` + The Middle Author; year/month from `date`; url is the permalink
- [ ] Obsidian chrome removed (callouts, Anki, wiki links, vault frontmatter)
- [ ] Citations via {% cite %} + _bibliography/references.bib
- [ ] Closing ## References + {% bibliography --cited_in_order %}
- [ ] Math: $$ + aligned; primes are ^{\prime}; visible braces are \\{ or \lbrace
- [ ] Obsidian ```tikz fences → TikZJax <figure>; tikzjax: true if any
- [ ] Raster images copied to assets/img/posts/
- [ ] Incomplete stubs and research-question sections skipped (or kept per user)
- [ ] Line breaks only at punctuation
```

## Example

**User:** Add content from `.../notes/sandbox/concepts/Transformers.md` as a blog entry under LLMs.

**Agent:** Read the note → write `_drafts/YYYY-MM-DD-transformers.md` with `kicker: "LLMs"` → convert the ` ```tikz ` fence via distill-tikz → add keys to `references.bib` → `{% cite %}` in prose → `{% bibliography --cited_in_order %}` → skip Hypotheses/Ideas.
